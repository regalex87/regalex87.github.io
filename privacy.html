PERSONAL APPLICATION

Privacy Policy

Effective October 11, 2026

1. Who operates this application

Marketing Knowledge Base is an owner-operated, non-commercial utility for organizing the operator's own private marketing knowledge. There are no public user accounts or third-party customers. For privacy inquiries, use the developer support email displayed on the Google OAuth consent screen.

2. Google user data accessed

After the owner authorizes access, this application may access Google Drive file names, IDs, folder locations, modification timestamps, file contents and permission metadata. It is designed to work on the owner's designated knowledge-base folders, source documents, processing state and backups.

The OAuth authorization may request the full https://www.googleapis.com/auth/drive scope. That permission technically allows the application to view, create, modify and delete files within the account's granted access; it is broader than any individual knowledge-base folder. Operational safeguards restrict intended automation to the selected work area. The owner can revoke access at any time.

3. How data is used

Drive data is used to discover source documents, compare versions, consolidate owner-selected knowledge, maintain processing records, perform integrity checks and make backups when those features are enabled. Data is not used for advertising, targeted marketing, data brokerage or unrelated profiling.

4. Where data is stored and processed

Authorized source documents reside in the owner's Google Drive. Selected knowledge snapshots, processing manifests, backups and change metadata may also be stored in a private GitHub repository controlled by the owner. GitHub Actions may process files during automated checks or updates. OAuth credentials may be retained as encrypted GitHub Actions secrets; access tokens are temporary.

The owner may use OpenAI/ChatGPT to review, summarize or synthesize knowledge-base materials as part of a separately authorized workflow. When used, relevant content may be processed by OpenAI under the settings and terms applicable to the owner's ChatGPT account. The app does not automatically send every Google Drive file to OpenAI.

5. Sharing and disclosure

Knowledge-base contents are not intentionally published on this website. Personal data is not sold. Google, GitHub and—when the owner chooses AI processing—OpenAI may process information as technology providers necessary to perform the described functions. The owner may also explicitly share selected outputs with collaborators.

6. Retention, access and deletion

The owner controls the retention and deletion of source files, GitHub snapshots, backups and activity logs. Copies may remain in backups or version history until the owner removes them according to the applicable service. To disconnect this application, revoke its Google Account authorization at Google Account connections, delete its stored GitHub Actions credentials, and remove retained copies if desired.

7. Security

The application uses OAuth authorization and private repository access controls. Automated workflows are designed to validate file identity, support recovery and avoid publishing private Drive contents. No system can guarantee absolute security. Permissions should be reviewed regularly and the owner should keep credentials private.

8. Changes to this policy

This policy may be updated as the personal automation evolves. Changes will be published on this page with an updated effective date. Material changes to the purposes of Google data use should be reviewed before new functionality is activated.
